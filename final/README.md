# Run Instructions

Please note that this project is a server-based web application, so the Node.js server must be running for the site to work properly and display its data correctly. Opening the HTML files directly in a browser will not show the full site. I have included this README.md file with the setup and run instructions.

## Requirements

- Node.js
- npm

## Install

```bash
npm install
```

## Start

```bash
npm start
```

## Open

```text
http://localhost:3004/
```
