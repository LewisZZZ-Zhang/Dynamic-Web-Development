About This Project

This map documents movie locations across New York City, with a focus on Marvel films. The goal is to connect scenes from film to real places and create a shared archive that is easy to explore.

Users can add locations, vote on entries, and discuss each place through comments. The project is community-driven and grows through contributions.

This project also hopes to help both New York residents and visitors find these locations more easily, making movie-location check-ins and city exploration more convenient.

This project encourages respectful, collaborative media mapping. Contributions should help people learn about local neighborhoods and film history without harming communities.

Please add accurate information, avoid spam, and keep discussions constructive. The map works best when contributors prioritize shared knowledge and public benefit.
